Method A: GitHub Web Upload (No Terminal Needed)
  1. Click 1. Download index.html above (and optionally manifest.json & .nojekyll).
  2. Log in to github.com/new.
  3. Set Repository name to ispr-news-report, choose Public, and click Create repository.
  4. Click "uploading an existing file" on the setup page, drag-and-drop index.html, and click Commit changes.
  5. Go to your repository Settings → Pages (left sidebar).
  6. Under Build and deployment → Branch, select main (folder /root) and click Save.
  7. In ~60 seconds, your live website URL will appear at https://<your-username>.github.io/ispr-news-report/!
Method B: Connect GitHub to Netlify (`isprbdnewsreport.netlify.app`)
  1. After uploading index.html to your GitHub repository in Method A, open app.netlify.com.
  2. Click Add new site → Import an existing project → GitHub.
  3. Pick your ispr-news-report repository and click Deploy site (leave build command blank).
  4. Go to Site configuration → Change site name and enter isprbdnewsreport.
  5. Every time you update index.html on GitHub, your live website automatically updates!
